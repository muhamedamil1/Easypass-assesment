Validate that the current scaffold plus repository contracts can deliver every assessment requirement without redesigning critical architecture. Do not implement product behavior.

## Context

Read `AGENTS.md`, all files under `docs/`, `.agent/PLANS.md`, and the active ExecPlan. Inspect the real scaffold, package configuration, Git state, and existing files.

- No product feature, SQL policy, auth flow, or invoice implementation.
- Do not weaken or silently change locked decisions.

- Identify API/version uncertainty and verify it from official primary docs.
- Keep the plan within the 4–6 hour budget.

## Done when

- The active ExecPlan reflects the real repository state and actual time budget.
- Every assessment requirement maps to a task, file area, and proof.
- Missing dependencies/configuration are identified for Task 01.
- Risks, contradictions, or proposed decisions are recorded.
- No critical architecture question remains hidden.
- Report files inspected, intended phase boundaries, and blockers.
